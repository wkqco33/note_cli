## 문서 작성 규칙

일관성을 위해 모든 문서는 다음 규칙을 따릅니다.

- **언어**: 한국어. 설명은 "~합니다"(합쇼체), 지침·체크리스트는 "~하세요".
- **제목**: 문서당 `#` 제목 하나, 섹션은 `##`, 하위는 `###`. 제목 다음에 한 줄 설명을 둡니다.
- **목록**: `-`를 사용하고, 중첩은 2칸 들여쓰기.
- **코드 블록**: 언어를 지정합니다 (`bash`, `go`, `yaml`, `json`, `text`).
- **표**: 구분선은 `| --- |` 형태로 통일합니다.
- **링크**: 저장소 내부 문서는 상대 경로로 연결합니다.
- **용어**: 프로젝트·저장소는 `note_cli`, 실행 파일·명령은 `ncli`로 표기합니다.
- **강조**: 굵게(`**`)는 핵심 용어에만 사용합니다.
